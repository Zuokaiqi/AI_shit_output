# AI_shit_output

本仓库用于收集AI喂给我的屎，不能我一个人吃，我要喂给全世界。

## 内容

`no_ai_style.md`按类别收录AI腔的词和句子，每条独立一行。

目前收录15类：

- 自我标榜
- 解释自己的用意
- 反问+规划下一步作结尾
- 破折号和弯引号
- 油腻煽情
- 表态式铺垫和自我宣誓
- AI语感套话
- 写作手法自评式标签
- 动作隐喻做预告
- 伪情绪反应和戏剧化表演
- 稻草人对比
- 营销号告诫和爆款文套话
- 附和式措辞
- 同义词堆砌式排比
- 形容词堆砌式自夸

## 怎么用

```bash
git clone <repository-url>
cd AI_shit_output
```

翻`no_ai_style.md`，对照AI输出命中哪条改哪条。
